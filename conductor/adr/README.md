# Architecture Decision Records

This directory contains architecture decisions that shape SPECTRE's design and operational constraints.

## Status values
- ACCEPTED: implemented and in active use
- PROPOSED: under review
- DEPRECATED: no longer recommended
- SUPERSEDED: replaced by a newer ADR

## Naming
Use ADR-NNNN-title-in-kebab-case.md.

## Template
Use TEMPLATE.md for new decisions.
